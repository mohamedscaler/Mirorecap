    Projets

    Chaque appel est rangé dans le bon projet. Quand un nouveau client apparaît, MiroRecap te propose de créer son projet, puis tient sa fiche à jour : statut, interlocuteurs, actions et point d'étape.

    Chaque projet est un dossier dans Comptes-rendus. Ce qui ne correspond à aucun projet va dans Divers.

    Réglages

    Analyse par l'IA

    MiroRecap détecte la fin de la connexion tout seul.
    La connexion se termine toute seule une fois connecté dans le navigateur.

    Avec ton abonnement (Claude Pro/Max ou ChatGPT Plus/Pro), pas de clé API : l'analyse compte dans les limites de ton abonnement. Claude : le navigateur s'ouvre, puis tu colles le code affiché dans la fenêtre Terminal. ChatGPT : tu te connectes dans le navigateur, c'est tout.

    Clé API Anthropic

    Optionnelle si tu utilises ton abonnement. Facturée à l'usage.

    Clé API OpenAI

    Optionnelle. Facturée à l'usage par OpenAI, indépendamment de ChatGPT Plus.

    Claude peut lire tes comptes rendus

    Ajoute MiroRecap aux connecteurs de l'app Claude sur ce Mac (et de Claude Code). Tu peux ensuite demander à Claude : « Qu'est-ce qu'on a dit avec la boulangerie Martin ? », « Quelles actions il me reste ? », « Prépare le devis à partir de mon dernier appel avec Paul ». Lecture seule, tout reste sur ton Mac. Quitte et rouvre l'app Claude après avoir connecté.

    Ton contexte

    L'IA s'en sert pour mieux comprendre tes appels et préparer, quand c'est utile, un mail prêt à envoyer (devis, récap, relance…) dans ton ton et avec ta signature. Elle tient aussi compte de ce qui s'est déjà dit sur le projet.

    Transcription

    Whisper tourne sur ton Mac, l'audio ne quitte pas ta machine. Le modèle choisi se télécharge une seule fois.

    Whisper écrit ces mots correctement quand il les entend. Les noms de tes projets sont ajoutés automatiquement.

    Quand un appel commence

    MiroRecap repère qu'un appel commence quand une autre app (Meet, Zoom, Teams, FaceTime, WhatsApp…) utilise le micro. En France, préviens toujours ton interlocuteur que tu enregistres.

    Meet, Zoom, Teams, FaceTime… MiroRecap enregistre ton micro et le son qui sort du Mac, puis les mélange. Au premier enregistrement, macOS demande l'autorisation « Enregistrement de l'écran et audio système » : seul l'audio est gardé. Avec un casque, le son est plus propre.
